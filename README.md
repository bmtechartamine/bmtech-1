# bmtech-1

## BMT Plan (`app/`)

Planificateur d'intérieur 2D/3D dans le navigateur : on dessine les pièces,
on ajoute portes et fenêtres, on meuble, puis on visite le résultat en 3D.
Voir [`app/README.md`](app/README.md) pour le lancer et le mettre en ligne.

## Dossiers

- `app/` : l'application (TypeScript, Vite, Three.js).
- `replica/` : le travail de préparation :
  - `recon.md` : la reconnaissance ;
  - `architecture.md` : l'architecture ;
  - `features.csv` : les fonctionnalités et leur état ;
  - `build-log.md` : le journal de construction.
- `.claude/skills/` : les compétences Replica (MIT) utilisées pour ce travail.
